# SYNCRIG 플랫폼 확장 구현 계획

현재 SYNCRIG는 `username/password` 기반 로컬 인증 + Steam/Riot OAuth, 하드웨어 매칭 엔진, 대시보드를 갖춘 풀스택 플랫폼입니다. 이 계획은 **4가지 핵심 기능**을 기존 `webplatform_w10` 코드베이스에 추가합니다.

---

## User Review Required

> [!IMPORTANT]
> 모든 기능은 **In-Memory Fallback DB** 환경에서 완벽하게 동작하도록 구현합니다 (PostgreSQL 없이 로컬 개발 가능). DB 스키마 변경은 PostgreSQL 연동 시에도 자동 마이그레이션됩니다.

> [!WARNING]
> 이메일 인증 기능은 **실제 SMTP 서버 없이 동작하는 시뮬레이션 방식**으로 구현합니다 (서버 콘솔에 인증 코드 출력 + 프론트엔드 자동 채움 옵션). 실제 메일 발송이 필요하면 Nodemailer + Gmail/SendGrid 연동이 추가로 필요합니다.

## Proposed Changes

### 1. 이메일 기반 회원가입 시스템

기존 `username/password` 방식을 **`email/password`** 방식으로 전환하고, 선택적 이메일 인증 코드 기능을 추가합니다.

#### [MODIFY] [db.js](file:///c:/Users/dlrjs/OneDrive/바탕 화면/대학교/webplatform/webplatform_git/webserviceplatform/webplatform_w10/server/src/config/db.js)

- `users` 테이블 스키마에 `email VARCHAR(255)`, `nickname VARCHAR(100)`, `email_verified BOOLEAN DEFAULT false`, `role VARCHAR(20) DEFAULT 'user'` 컬럼 추가
- `email_verification_codes` 테이블 신규 생성 (In-Memory + PostgreSQL 양쪽)
- MOCK_DB users 배열에 email, nickname, role 필드 추가
- In-Memory 쿼리 파서에 email 기반 조회/삽입 로직 추가

```diff
 CREATE TABLE IF NOT EXISTS users (
   id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
-  provider VARCHAR(50) NOT NULL,
-  provider_id VARCHAR(255) NOT NULL,
+  email VARCHAR(255) UNIQUE,
+  nickname VARCHAR(100),
+  provider VARCHAR(50) NOT NULL DEFAULT 'local',
+  provider_id VARCHAR(255) NOT NULL,
   password_hash VARCHAR(255),
+  email_verified BOOLEAN DEFAULT false,
+  role VARCHAR(20) DEFAULT 'user',
   linked_providers JSONB DEFAULT '[]'::jsonb NOT NULL,
   subscription_status VARCHAR(50) DEFAULT 'free' NOT NULL,
   ...
 );
```

```sql
CREATE TABLE IF NOT EXISTS email_verification_codes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) NOT NULL,
  code VARCHAR(6) NOT NULL,
  expires_at TIMESTAMP NOT NULL,
  used BOOLEAN DEFAULT false
);
```

```sql
-- 게시글 테이블
CREATE TABLE IF NOT EXISTS community_posts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  category VARCHAR(50) NOT NULL DEFAULT 'free',
  title VARCHAR(200) NOT NULL,
  content TEXT NOT NULL,
  likes INT DEFAULT 0,
  views INT DEFAULT 0,
  is_pinned BOOLEAN DEFAULT false,
  is_hidden BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 댓글 테이블
CREATE TABLE IF NOT EXISTS community_comments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  post_id UUID NOT NULL REFERENCES community_posts(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  content TEXT NOT NULL,
  is_hidden BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 좋아요 테이블 (중복 방지)
CREATE TABLE IF NOT EXISTS community_likes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  post_id UUID NOT NULL REFERENCES community_posts(id) ON DELETE CASCADE,
  user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(post_id, user_id)
);
```
