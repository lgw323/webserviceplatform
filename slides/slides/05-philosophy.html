05 / ARCHITECTURE PHILOSOPHY
기술 철학 — 서비스 가용성을 위한 요청 처리 흐름
01
UI
REQUEST START
Client UI 레이어
React 18 · Zustand · Tailwind
유저가 브라우저에서 게임 최적화 추천 요청이나 커뮤니티 상호작용 등의 요청을 보내는 프론트엔드 시작점입니다.
02
JWT
AUTH & ROUTING
Server 인증 및 처리 레이어
Node.js · Express · JWT Token
클라이언트에서 전송된 보안 검증 토큰(JWT)의 유효성을 서버리스 배포 환경에서 안전하게 인증하고 백엔드 라우팅 및 데이터 처리를 조율합니다.
03
DB
DATA FAULT TOLERANCE
Data 저장 및 우회 가동
Postgres · In-Memory Fallback
최적화 데이터베이스를 조회하며, 만약 외부 DB 서버 연결에 장애가 발생할 경우 즉시 In-Memory Mock DB로 자동 스위칭(즉각 우회)하여 서비스 가용성을 보장합니다.
사용자의 단일 요청(Request)이 웹 프론트엔드와 백엔드를 거쳐 데이터베이스 레이어까지 지속 가능하고 안정적으로 흐르는 아키텍처입니다.
