05 / ARCHITECTURE PHILOSOPHY
기술 철학 — 왜 이 기술인가
Client Layer
React 18 + Vite · Zustand · TailwindCSS
• 컴포넌트 기반 SPA 최적화 관리 및 Redux 대비 보일러플레이트 90% 절감
• 다크/라이트 테마 런타임 제어 및 정적 렌더링 무오류 가동
Server Layer
Node.js + Express · Passport.js · JWT 이중 토큰
• Steam OpenID + Riot OAuth 2.0 연동 및 무상태 Serverless 환경 이중 보안
• JS 풀스택 단일 언어 구현으로 런타임 통신 효율성 강화
Data Layer
PostgreSQL (Neon) · In-Memory Fallback
• 클라우드 관계형 데이터 모델링 및 Vercel 네이티브 연동 최적화
• 메인 DB 장애 감지 시 In-Memory Fallback 아키텍처로 실시간 극복 (서비스 중단 0초)
