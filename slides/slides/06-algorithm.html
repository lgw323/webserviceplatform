GPU 오차(3칸) + CPU 오차(4칸)
= 총 오차 합계 7
각 하드웨어의 성능 오차를 있는 그대로 합산합니다. 이를 통해 특정 부품의 성능이 모자라 병목 현상이 일어나는 경우를 왜곡 없이 그대로 짚어내어 정확한 추천을 내려줍니다.

REJECTED

격자를 무시하고 대각선으로 가로지릅니다.
수학적으로 각 오차를 제곱해서 더합니다.

= 총 오차 합계 5 (제곱 왜곡 발생)
오차를 제곱하여 계산하기 때문에, 특정 부품 하나의 큰 성능 부족 오차가 비정상적으로 뻥튀기(제곱)되어 전체 매칭 지표를 심각하게 왜곡합니다.
