12 / FAULT TOLERANCE ARCHITECTURE
시스템 아키텍처 & 장애 복원력 (Resilience)
CLIENT LAYER React 18 · TailwindCSS · Zustand
Axios Interceptor 장애 방어: 401 Unauthorized 오류 감지 시 큐에 대기 중인 요청을 보존하고, 백엔드로부터 새로운 Access Token을 자동 발행받아 사용자 이탈 및 UX 단절을 원천 방어합니다.
SERVER LAYER Node.js · Express · Passport.js · JWT
보안 중심 분산 가동: Vercel Preview 클라우드 분산 배포 환경에서 동적 OAuth 콜백 호스트 주소(`x-forwarded-host`)를 검증하고 세션 만료와 인증 토큰을 실시간으로 안전하게 관리합니다.
DATA LAYER Vercel Serverless Postgres ↔ In-Memory Fallback
In-Memory Fallback 이중화: 클라우드 DB 장애 등으로 예기치 않은 데이터 노드 단절 발생 시, 캐싱된 가중치 인메모리 노드로 자동 전이하여 핵심 최적화 알고리즘 엔진을 중단 없이 즉시 상시 복구합니다.
